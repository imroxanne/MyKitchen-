# Рецепты MyKitchen

Каждый рецепт — JSON-файл `content/recipes/<партия>/<slug>.json` в формате
`scripts/recipes/schema.ts` (`RecipeFile`). Из партии генерируется миграция:

```bash
node scripts/recipes/build-migration.ts batch-01        # записать/обновить миграцию партии
node scripts/recipes/build-migration.ts --check-all     # проверка в CI
```

## Правила

- **Только законные источники.** Сейчас — «Книга рецептов» Викиучебника
  (ru.wikibooks.org), лицензия CC BY-SA 4.0. Для каждого рецепта указываются ссылка на
  страницу, номер версии страницы, ссылка на историю правок (авторы), лицензия и что изменено.
- **Ничего не выдумывать.** Чего нет в источнике — `null` (время, порции, выход) или текст
  источника вместо числа («по вкусу»). Количества не «уточняются» по догадке.
- **Статусы.** `sourceCheck` ставится только после сверки всех ингредиентов и шагов с
  указанной версией страницы. «Проверен приготовлением» в файлах не ставится — только по
  факту приготовления (пункт C1).
- **Партии неизменны** после применения к облачной БД: новые рецепты — новой партией.

## Лицензия

Рецепты, адаптированные из Викиучебника, распространяются на условиях
[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/deed.ru) с указанием авторов
оригинальной страницы (ссылка на историю правок в каждом файле).
