## A1 — основа проекта с нуля (2026-10-28)

Критерий: проект запускается локально; создан начальный интерфейс; настроен Git.

**Исходное состояние.** Репозиторий содержал только `README.md`; прототипа нет — проект
создаётся с нуля (дорожная карта обновлена с учётом этого).

**Сделано.**

- Стек выбран и обоснован (docs/ARCHITECTURE.md): React + TypeScript + Vite, Supabase Free, Vercel Hobby.
- Начальный интерфейс: оболочка с навигацией по шести разделам ТЗ (телефон — нижняя панель,
  десктоп — верхняя), разделы честно помечены как нереализованные с указанием пунктов,
  экран `/status` с проверкой связи с БД.
- Git: ветка `a1-foundation`, осмысленные коммиты, `.gitignore` для секретов (`.env.*`).
- Supabase: облачный проект `mykitchen`, локальная конфигурация `supabase/`, миграция `app_health()`.
- Vercel: проект `mykitchen`, переменные окружения Production/Preview, SPA-перенаправления;
  сборки из GitHub работают.
- CI (GitHub Actions): lint, типы, юнит-тесты, сборка, Playwright (телефон + десктоп),
  применение миграций к чистому Postgres. Keep-alive для бесплатного Supabase.
- Документы: ARCHITECTURE, ENVIRONMENTS, DATA_MAP, CLAUDE.md для следующих сессий.

**Проверено.**

- Локально: `npm run check` — lint, типы, 10 юнит-тестов, сборка, 6 e2e-тестов (телефон и десктоп) проходят;
  `npm run dev` поднимает приложение.
- Облачная БД: миграция применена, `app_health()` вызывается от роли `anon`, советник безопасности Supabase замечаний не нашёл.
- Vercel: сборка ветки в состоянии READY, прямой адрес `/pantry` отдаёт приложение, адрес и ключ Supabase попали в сборку.

**Известные ограничения.**

- Сборка ~530 КБ JS (большая часть — supabase-js); разделение кода — в E4.
- Сайт закрыт Vercel Authentication (виден только владелице после входа в Vercel).
  Собственного входа в приложение пока нет — E1.
- Регистрация в Supabase Auth открыта по умолчанию — закрыть при включении входа (E1).
- Из среды разработки ИИ нет сетевого доступа к `*.supabase.co` и `*.vercel.app`, поэтому
  связка «браузер на сайте → БД» проверяется открытием `/status` на сайте.
