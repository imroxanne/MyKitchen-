## A1 — аудит и основа (2026-10-28)

**Аудит исходного состояния.** В репозитории был только `README.md`; прототипа в
репозитории, Supabase, Vercel и опубликованных артефактах не найдено. Принятых готовых
функций нет — проект начат с нуля, все разделы сейчас заглушки.

**Сделано.**

- Приложение React + TypeScript + Vite, маршруты шести разделов ТЗ (заглушки с указанием пунктов),
  экран `/status` с проверкой связи с БД.
- Supabase: облачный проект `mykitchen` (Free), локальная конфигурация `supabase/`,
  миграция `app_health()`.
- Vercel: проект `mykitchen`, переменные окружения для Production/Preview, SPA-перенаправления.
- CI: lint, типы, юнит-тесты, сборка, Playwright (телефон + десктоп), миграции с нуля на чистом Postgres.
- Keep-alive для бесплатного Supabase.
- Документы: ARCHITECTURE, ENVIRONMENTS, DATA_MAP.

**Известные ограничения.**

- Сборка ~530 КБ JS (из них большая часть — supabase-js); разделение кода — в E4.
- Сайт закрыт Vercel Authentication (виден только владелице после входа в Vercel). Собственного входа в приложение пока нет — E1.
- Регистрация в Supabase Auth открыта по умолчанию — закрыть при включении входа (E1).
