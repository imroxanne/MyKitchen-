# Заметки для кодового ИИ

- Требования: `docs/MyKitchen_TZ.md`; порядок и правила работы: `docs/MyKitchen_Roadmap.md`;
  текущий статус пунктов: `docs/STATUS.md` — обновлять при закрытии пункта.
- Git: работать в ветке пункта, после зелёного CI **самостоятельно вливать в `main`** (указание
  заказчицы: рабочая версия на Vercel всегда должна быть актуальной). `main` = production.
- Заказчица не программист: делать работу самому, отчитываться кратко по-русски
  (что сделано / что проверено / что мешает / следующий ID).
- Стек: React 19 + TS + Vite (SPA), React Router 7, Supabase (Postgres/Auth/RLS), Vercel Hobby.
- Схема БД меняется только миграциями в `supabase/migrations/`; при применении к облаку версия
  должна совпадать с именем файла. Каждая пользовательская таблица — с `user_id` и RLS.
- Репозиторий публичный: никаких секретов и личных данных в Git. В `VITE_*` — только публичные значения.
- Перед коммитом: `npm run check`. Код форматируется Prettier, комментарии и интерфейс — на русском.
- Тестовые данные помечать явно, не выдавать за проверенные рецепты/КБЖУ/цены.
